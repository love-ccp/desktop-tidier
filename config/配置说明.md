# 配置编写说明（config.json）

> 配置文件是**严格 JSON**（不支持注释）。示例见同目录 `config.example.json`，首次运行时程序会在配置目录自动生成 `config.json`（即示例的拷贝）、`config.example.json`、`schema.json`、`lexicon.txt` 与本文档。
> 编辑建议：用支持 JSON Schema 的编辑器（VS Code 等）打开，`"$schema"` 字段会触发字段补全与实时校验。

## 处理流程（三步）

```
桌面 source_dir ──(后缀 + mtime 超过 min_age_days 天)──> inbox_dir（指定目录）
inbox_dir ──(词库关键词匹配)──> course_dir/{分组}/（无匹配 → {default_group}/）
course_dir/** ──(每 interval_hours 压缩归档)──> archive_dir/{rename_pattern}.zip，然后清空 course_dir 至回收站
```

每次"收录"（文件从桌面进入 inbox 或 course_dir）都会按 `indexer.entry_format` 追加一条台账记录，编号顺延。

## 字段逐一说明

### watcher（监听与筛选）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `source_dir` | string | `""` | 源目录（要整理的桌面）。**留空 = 自动探测系统桌面**。Windows 如 `C:/Users/教师/Desktop`，Linux 如 `/home/教师/Desktop`。 |
| `extensions` | string[] | 见示例 | 要移动的**后缀列表**，不带点、小写。希沃课件常见 `enbx`（希沃课件格式）、`pptx/ppt`、`doc/docx`、`pdf`、`wps/et/dps`。 |
| `min_age_days` | int | `3` | 文件**修改时间**超过 N 天才处理（已锁定用 mtime，非创建时间）。 |
| `debounce_ms` | int | `400` | 文件事件防抖（毫秒），避免瞬间大量事件重复处理。 |
| `scan_interval_secs` | int | `172800` | **扫描整理频率**（秒）。默认 `172800` = 两天扫描整理一次，可自定义；兜底全量扫描也用它（防事件遗漏）。 |

### storage（目录）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `inbox_dir` | string | `storage/待分类` | 步骤 1 的"指定目录"。 |
| `course_dir` | string | `storage/课件库` | 步骤 2 的分组根；文件最终进 `course_dir/{分组}/`。 |
| `archive_dir` | string | `storage/归档` | 步骤 3 的 zip 归档目标。 |
| `recycle_after_archive` | bool | `true` | 归档成功后是否把 `course_dir` 内文件**清空到回收站**（可恢复，非彻底删除）。 |

> 所有相对路径均相对于**配置文件所在目录**（即 config/ 的上一级）。建议保持相对路径，便于整套目录随 exe 拷走。

### classifier（关键词分类）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `lexicon_path` | string | `config/lexicon.txt` | 词库路径。 |
| `lexicon_encoding` | string | `auto` | 词库编码：`auto`（chardetng 自动探测）/ `utf-8` / `gbk`。 |
| `default_group` | string | `未分类` | 文件名未命中任何关键词时的分组。 |

### archiver（压缩归档）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `interval_hours` | int | `24` | 每隔多少小时归档一次。 |
| `zip_level` | int | `6` | zip 压缩等级，**需求固定为 6**（1~9，越高越慢越小）。 |
| `rename_pattern` | string | `{date}_{seq}_course.zip` | 归档文件重命名规则。占位符：`{date}`=日期 `%Y%m%d`、`{time}`=时间 `%H%M%S`、`{seq}`=当日序号（自动递增，避免重名）。 |

### indexer（MD 台账）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `md_path` | string | `storage/台账.md` | 台账文件路径。 |
| `md_encoding` | string | `auto` | 读取现有文件编码后**按相同编码顺延追加**；`auto`=自动探测。 |
| `entry_format` | string | `{no}. {filename} - {group} - {date}` | 单条记录格式。占位符：`{no}`=编号（顺延）、`{filename}`=文件名、`{group}`=分组、`{date}`=操作日期（授时校正后的本地日期 `%Y-%m-%d`）。 |

### logger（日志，单文件）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `file` | string | `logs/organizer.log` | 日志文件。始终只有一个日志文件。 |
| `level` | string | `info` | `trace`/`debug`/`info`/`warn`/`error`。 |
| `max_bytes` | int | `1048576` | 超过此字节数后，旧日志改名 `.bak`（仅保留 1 份），新建同名文件继续写。 |

### timesync（授时）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 是否启用授时。 |
| `servers` | string[] | `["https://www.baidu.com"]` | HTTPS 授时 URL 列表，**读取响应 `Date` 头**；依次尝试直到成功。国内建议用可直连站点。 |
| `interval_hours` | int | `1` | 启动时立即授时一次，之后每隔 N 小时授时并落盘偏移。 |
| `timeout_secs` | int | `10` | 单次请求超时（秒）。 |

> 授时失败不阻塞程序：退回本地时钟，保留上次偏移，并在日志记录。

### notify（系统通知）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 系统通知总开关。 |
| `app_name` | string | `课件整理助手` | 通知来源名。 |

### concurrency（并发）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `max_parallel_ops` | int | `4` | 并发文件操作数（移动/归档）。学校机械盘建议 2~4，SSD 可 8。 |

## 校验错误格式（示例）

坏配置会**跳过整个配置文件、保留旧值**，并发送系统通知。错误消息形如：

```
配置校验失败：字段 "watcher.min_age_days" 期望 非负整数(0~36500)，实际得到 "abc"
建议：请改为整数，例如 3
```

错误级别日志同样会触发系统通知（受 `notify.enabled` 控制）。

## 热重载

- 修改 `config.json` 或 `lexicon.txt` 后，程序检测到文件变更会自动重载（防抖 400ms）；配合托盘"打开配置文件目录"即可边改边生效。
- 新配置先解析到临时结构，**校验通过才原子替换**；失败则保留旧配置并发通知。
- 词库每行独立解析，**单行出错仅跳过该行**并通知，不中断整体加载。

## 词库（lexicon.txt）

每行一条 `关键词<TAB>分组`；`#` 开头为注释；空行跳过。关键词按**整条文件名（含扩展名）**、ASCII 大小写不敏感匹配。示例：

```
# 关键词<TAB>分组
二次函数	数学
三角函数	数学
牛顿定律	物理
电磁感应	物理
```

## 托盘菜单（固定 4 项，自上而下）

右键托盘图标（**刷子样式**）出现的菜单固定为：

1. **设置开机自启**：勾选态切换，写入系统开机自启（Windows 注册表 Run 键 / Linux `~/.config/autostart/*.desktop`），点击即切换并同步勾选态。
2. **立刻整理**：立即执行一次完整整理（扫描 → 分类 → 移动 → 归档 → 记账），不等 `scan_interval_secs`。
3. **打开配置文件目录**：用系统文件管理器（explorer / xdg-open）打开配置目录，方便编辑 `config.json` / `lexicon.txt`。
4. **退出**：优雅退出（各任务 graceful shutdown → 释放单实例锁 → 删除托盘图标）。

> 开机自启状态存在操作系统中，不写入配置文件；程序启动时读 `is_autostart_enabled` 显示勾选态。
